# 👵 Interactive - Interfaz de Accesibilidad

**Interactive** es una propuesta de interfaz diseñada específicamente para reducir la brecha digital en personas mayores. Inspirada en la necesidad de interfaces intuitivas, esta aplicación elimina la complejidad tecnológica para centrarse en lo esencial: la comunicación y la seguridad.

## 🎯 Objetivo del Diseño
El diseño aborda el "caos tecnológico" (representado en la comparativa de nuestra visión del proyecto) mediante una interfaz de **carga cognitiva mínima**.

### Características Principales:
* **Contraste Alto:** Colores vibrantes y distintos para identificar funciones por color rápidamente.
* **Tipografía Escalada:** Textos de gran tamaño (28pt+) para usuarios con presbicia o dificultades visuales.
* **Botones de Área Amplia:** Diseño basado en la *Ley de Fitts*, maximizando el área de contacto para evitar errores de precisión.
* **Sin Jerarquías Complejas:** Todo lo importante sucede en una sola pantalla.

## 📱 Pantallas
La interfaz presenta tres pilares de acción inmediata:
1.  **Llamar Familia:** Acceso directo a contactos de confianza.
2.  **Emergencia:** Botón de auxilio con alta visibilidad (Rojo SOS).
3.  **Guía de Voz:** Asistente auditivo para navegación asistida.

## 🛠️ Tecnologías Utilizadas
* **Framework:** Flutter (Canal estable).
* **Lenguaje:** Dart.
* **Librerías de UI:** Material 3 (con widgets personalizados para accesibilidad).
